# DobroVozTurk - лендинг

Десктопный лендинг сервиса доставки товаров из Европы в Россию.

Реализовано: hero с интерактивным 3D-глобусом (маршруты Европа - РФ),
блок показателей, категории товаров с логотипами магазинов,
блок гарантий. Анимации: GSAP + ScrollTrigger, Lenis, Three.js,
покадровые секвенции крана и грузовика.

На экранах уже 992px показывается заглушка: версия только для десктопа.
